# 俯视战场 3D · 优化版 v2

原版在 `E:\ai网页\final-game\`，这一份是它的「只改版式」版本。
**文案、板块、顺序、表单规则、游戏本体全部没动**，仍然是：无框架、无外部字体、无外部图片。

## 改了哪些

| 项目 | 原版 | v2 |
| --- | --- | --- |
| 字体栈 | `sans-serif` | 中文优先的系统字体栈（仍然本地字体） |
| 首屏 | 60vh，纯半透明遮罩 | 66vh，上下渐变 + 底部过渡，标题带轻微光晕 |
| 标题层级 | h1 48 / h2 24 | h1 58 / h2 26，h2 左侧加一条青色竖线 |
| 正文 | 16px/1.8 | 16px/1.85，行宽收到 62ch |
| 卡片 | 直角、单色底 | 微渐变、圆角 3px、hover 上浮 + 边框提亮 |
| 图片 | 1px 边框 | 圆角 3px + 阴影 |
| 表单 | 方块堆叠 | 居中面板、输入聚焦描边、提示文字分成功/失败色 |
| 顶栏 | 纯色 sticky | 半透明 + 毛玻璃，滚动后加阴影，当前板块高亮 |
| 底栏 | 纯色 | 半透明 + 毛玻璃 |
| 锚点跳转 | 会被顶栏挡住 | `scroll-margin-top: 64px` |
| 动效 | 无 | 板块滚动淡入（JS，3 秒兜底），尊重 `prefers-reduced-motion` |
| 无障碍 | 无 | `:focus-visible` 描边 |

## 没改哪些

- 所有文案、标题、段落、列表项
- 六个板块的 id（`#play #action #enemy #battlefield #modes #startGame`）
- 表单校验逻辑（账号密码 / 姓名 / 身份证 7–14 位 / 未成年提示）
- `about.html` 的文字
- 游戏本体 `assets/play/moba3d.html` 与 `three.min.js`
- 图片资源（同名同尺寸）

## 文件结构

```
final-game-v2/
├─ index.html        原结构 + 一段增量 <script>（只做表现增强）
├─ about.html        内联样式重写，文案不变
├─ css/style.css     重写，选择器与原版同名
├─ assets/           图片与游戏本体，原样复制
└─ 说明-v2.md        本文件
```

## 两版对照

打开 `E:\ai网页\final-game-compare.html`：左右并排，可切「只看原版 / 只看新版」。
两边各自滚动，左上角标签可单独打开某一版。

## 回滚

原版 `final-game\` 一直没动。v2 出问题直接删目录重来：

```powershell
Remove-Item "E:\ai网页\final-game-v2" -Recurse -Force
```

# 《俯视战场 3D》· 作业说明

## 一、三个页面

| 文件 | 内容 |
|---|---|
| index.html | 首页：首屏 + 六个板块 + 开始游戏表单 |
| about.html | 关于：我的 3D 游戏世界 |
| assets/play/moba3d.html | 游戏本体（JS 没改） |

## 二、300 字说明

本网站是 3D 俯视角竞技游戏《俯视战场 3D》的介绍页，分首页、关于和游戏三个页面。首页用一张实机图做首屏，下面六个板块：玩法、动作、敌人、战场、模式，最后是开始游戏表单；关于页写做 3D 的过程；游戏页直接打开游戏。整体深色，内容收在 1100px 中线里，手机端变一列。CSS 只有 67 行，深色底、两栏图文、卡片和底部导航；开始游戏表单账号密码随便填，身份证只看第 7–14 位的出生日期，未成年提示一句“只能玩一小时”，成年提示验证通过，两种都能进游戏。游戏本体没改 JS，直接放在 `assets/play`。页面没有框架、没有外部字体。

## 四、怎么改

## 五、运行与验收

1. VSCode 打开 `final-game`，右键 `index.html` → Live Server。
2. 顶部导航能跳到对应板块；“开始游戏”跳到底部表单。
3. 表单：账号密码随便填，身份证第 7–14 位是出生日期；未成年提示一句，成年提示验证通过。
4. “进入游戏 →”打开 `assets/play/moba3d.html`，游戏 canvas、Three.js 正常。
5. 1440 / 375 无横向滚动。
